## Hard Rule for Settings

Do not hardcode operational settings inside workflows if those values belong in settings.

That includes:

* Organization ID
* Submitter ID
* Billing NPI
* Rendering provider
* Payer ID
* Stripe account
* Portal visibility
* Mailroom filing behavior
* Gmail polling behavior
* Appointment status rules
* Documentation required fields
* Charge readiness rules
* ERA posting behavior
* Claim generation behavior
* Payment/refund behavior

Seed/default values are allowed, but active workflow behavior must read from canonical settings.
